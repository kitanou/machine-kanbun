# 5 分で分かる現在までの成果

各主張の末尾の ID は [RESULTS.md](https://github.com/kitanou/machine-kanbun/blob/main/RESULTS.md) の行(根拠は Issue 番号)。**確認済み**と**仮説・未検証**を分けて書く。

## 1. 何を試したか
LLM に渡す文脈(会話履歴・記憶・文書)を、意味を保ったまま少ないトークンで表せるか。機械漢文(漢字 + 構造記号)から始め、日本語の解析器ベースの圧縮(SCF)、LLM による意味中心の書き直し(SeCF)、Chat 履歴と長期記憶での利用へと進めた。評価はローカルモデル(主に gemma-4-12b、qwen3-8b)で行っている。

## 2. 何が分かったか(確認済み)
- **圧縮の大半は自然言語の文法的冗長性の除去から来る**。自然言語 → 簡潔な日本語でトークンは -48〜-61%、精度は変わらない(R-A1)。漢字化・構造記法には追加の利得がない。構造化は精度を下げる(R-A3、R-A4)。
- **何を削ってよいか**: 助詞・丁寧語・フィラーは削除できる。否定・不確実性・語順・主語を消すと壊れる(R-C3)。
- **SCF の変換は十分に安い**(1 通 0.05 ms、R-C1)。トークナイザによって効果が逆転する(R-C2)。
- **Chat 履歴**: 古い履歴を SCF-L1 / SeCF-L1 にしても、NF の回答の文体は汚染されない(R-D1、R-D12)。**SeCF-L1 は古い事実の想起が NF 並み**で圧縮率も良い一方、**SCF-L1 は想起が -10〜-17pt**(願望・完了を取り違える。R-D8、R-D9、R-D11)。
- **同じ token budget で古い履歴を切り捨てる NF と比べると**、SeCF-L1 が +14〜20pt 上回るが、理由は「より多くの履歴が残る」こと(R-D16、R-D17)。
- **Long-term Memory**: 検索の最良は BM25(SCF-L1)+ ベクトル(NF)の Dual。SeCF-L1 に検索上の独自の利点はない(R-M1)。
- **パーソナル記憶の密度**: 会話から抽出した記憶では、密度の大半は抽出が作り(蒸留 0.07〜0.17)、SeCF-L1 は +9〜10%(0.90〜0.92)。全文を渡す条件では正答差を検出できず、同一 budget で +3〜4pt、キャッシュでは検出できなかった(R-N1〜N7、合成データ・gemma 1 モデル)。
- **Prefix / KV キャッシュ**: キャッシュにヒットすると TTFT は 1.3〜4 秒に落ち、NF と SeCF-L1 の差はほぼ消える(SeCF-L1 のトークン削減はヒット時に効かない)。SeCF-L1 の利点は、ミス・部分ヒットでの約 20% の短縮と、限界付近の保持に限られる(R-K1〜K4)。
- **変換コスト**: SeCF-L1 は、25〜2000 トークンのどの長さでも**同期変換では NF より遅い**(変換は TTFT の節約の約 22 倍)。事前変換した記憶でも、1 件あたり約 24〜56 回の再利用で回収(R-L3、R-L4)。圧縮率は文章長ではなく文体で決まる(R-L1)。

## 3. 予想外だったこと
- SCF に変えると長文脈で精度が +20pt 上がるように見えた結果は、質問を増やすと**再現しなかった**(R-C4)。
- 「圧縮した履歴のほうが事実に言及されやすい」は、語の有無の指標による見かけで、正答率では逆転した(**取り下げ**、R-D4)。
- 初回の「SeCF」(`{}` 型の構造化)は SeCF-L5 相当で、SeCF-L1 より想起が大きく劣った(R-D8)。
- 状態が変わる記憶を SeCF-L1 で統合しても、最新状態の取り出しは良くならなかった(R-M4)。ただし、この評価の 3 択 QA の指示は「迷い」を過小評価していたと後で分かり、再測定が必要(R-Q1、R-Q2)。

## 4. 現時点で言えること
- 日本語の Chat では、**直近は NF、会話中の圧縮は SCF-L1、書き直し済みの古い履歴・記憶は SeCF-L1**という使い分けが妥当と見られる(三層履歴は SeCF-L1 一本と同等の想起を同期変換 14〜86 ms で出せた。R-D14。ただしこの二段構成の運用全体は未検証)。
- SCF-L1 が失うのは、助詞・活用の削除で落ちる状態の区別(願望・完了)と見られる(#49・#51 の結果からの推論。直接の因果検証ではない)。

## 5. まだ言えないこと(仮説・未検証)
- SeCF-L1 の優位が、保持量以外の**表現そのものの効果**(Signal / Noise の改善)を持つか(R-D17。評価が天井のため検出できていない)。
- 多言語で SCF が共通の意味構造に収束するか(粗い SCF では収束せず、形態素解析つき SCF は未実施。R-B7)。
- 実会話での再現、人手評価、より大きいモデルでの結論の保持。
