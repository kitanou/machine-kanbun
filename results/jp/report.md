# Issue #20 日本語 L0 と既存解析器ベースの簡易 L1 の比較

対象は日本語の会話文のみ。簡易 L1 は既存の形態素解析器(SudachiPy / MeCab(fugashi, unidic-lite) / Janome)と係り受け解析器(GiNZA)の出力を軽量ルールで写像したもので、LLM は使わない。変種: **m** 形態素のみ(空白区切り)、**g** m を空白なしで連結、**p** 格助詞を残す、**c** 接続を残す、**d** GiNZA の係り受けで節に分け省略された主語を補う、**naive** 解析器なしでひらがな連を削るだけ。

## 変換例(課題文の例)

```text
L0       : 昨日、田中さんと久しぶりに話したんだけど、どうも会社を辞めようか迷っているらしい。ただ、まだ決めたわけではないみたい。
sudachi-m: 昨日 田中 久しぶり 話す た 会社 辞める う 迷う らしい / まだ 決める た ない みたい
sudachi-g: 昨日田中久しぶり話すた会社辞めるう迷うらしい/まだ決めるたないみたい
sudachi-p: 昨日 田中と 久しぶりに 話す た 会社を 辞める う 迷う らしい / まだ 決める た ない みたい
mecab-m  : 昨日 田中 久しい 話す た 会社 辞める う 迷う らしい / まだ 決める た ない みたい
janome-m : 昨日 田中 久しぶり 話す た どうも 会社 辞める 迷う らしい / まだ 決める た ない みたい
ginza-d  : 昨日 田中 久しぶり 話す た / 田中 会社 辞める / 田中 迷う らしい / 田中 まだ 決める た ない みたい
naive    : 昨日 田中 久 話 会社 辞 迷 決
```
