# Issue #67: 「迷い(まだ決めていない)」を「いいえ」と読む誤りの原因 — 質問形式 × 表現

[← README に戻る](../README.md) ・ [#62 状態が変わる記憶](exp-mem-update.md)

#62 で、最後が「迷い」に戻る遷移(予定 → 迷い)が、最新の記憶だけを渡す上限でも 0.67、統合メモで 0.17 と低かった(統合メモは「現在: 起業を迷っている」と正確なのに、LLM は「いいえ」と答えた)。この誤りの原因が、質問の形式(指示・選択肢)・記憶の表現・モデルの先入観のどれかを切り分ける。あわせて、#20 以降の 3 択 QA(はい / いいえ / 未確定)が UNDECIDED を過小評価していないかを確かめる。`machine_kanbun/jpstate.py`(`run` / `report`)、`scripts/run_state67.sh`、結果は [results/jp4/state_report.md](../results/jp4/state_report.md)・`state_google_gemma-4-12b.jsonl`。

**設計**: #59 と同じ記憶ベンチ(`jpdata.make_memories(1000, seed=28)`)から、状態ごとに 15 件(計 105 件)を**単一の記憶**として渡す(検索の影響を除く)。表現は NF / SCF-L1(sudachi-m)/ SeCF-L1(#59 のキャッシュ)。質問形式は 4 種(gemma-4-12b、温度 0、決定的採点): **V0** 現行の 3 択(`jpllm.INSTR`)、**V1** V0 + 「『迷っている』『まだ決めていない』は、していないのではなく決まっていない状態なので『未確定』。『しなかった』『しない』『予定』『したいと思っている』は『いいえ』」という注意、**V2** 状態 7 択(#49 と同じ選択肢)の回答を 3 択に写像、**V3** V0 + few-shot 3 例(UNDECIDED を「未確定」とする例を含む)。4 形式 × 3 表現 × 105 件 = 1,260 回。

UNDECIDED のペア比較(記憶単位、表現 3 通りの平均、符号反転の置換検定): V1 − V0 **+20.0pt [+11.1, +26.7]、p=0.004**、V2 − V0 **+24.4pt [+15.6, +33.3]、p=0.002**、V3 − V0 -11.1pt [-26.7, +6.7]、p=0.345。V0 での表現間: SeCF-L1 − SCF-L1 **+60.0pt**(p=0.004)、SCF-L1 − NF **-46.7pt**(p=0.038)、SeCF-L1 − NF +13.3pt(p=0.49)。

- **H1(質問形式仮説)は支持**: 指示に「迷い・まだ決めていない = 未確定」の注意を足す(V1)と、UNDECIDED が +20.0pt 上がり(基準 ≥20pt、p<0.05)、「いいえ」系は 1.000 のまま変わらない(悪化なし)。**誤りの大半は質問の指示の不足で、モデルの先入観で直らない問題ではない(H2 は支持されない)**。
- **H3(表現仮説)も支持**: 現行の指示(V0)では、UNDECIDED の誤りは **SCF-L1 に集中**する(NF 0.87、SCF-L1 0.40、SeCF-L1 1.00)。**V0 の誤答 11 件のうち 9 件が SCF-L1**(「いいえ」7、「はい」2)、2 件が NF(「いいえ」)。SCF-L1 の記憶は「迷う らしい / まだ 決める た ない みたい」のような断片になり、「ない」「た」が否定・完了と読まれやすいと見られる(原因の直接検証ではない)。V1 の注意で SCF-L1 は 0.87 まで戻る。SeCF-L1 は元から 1.00。
- **H4(測定の妥当性)も支持**: 状態 7 択を 3 択に写像すると、未確定系は 1.000(V0 は 0.911)で、**現行の 3 択の指示は未確定系(特に UNDECIDED)を過小評価していた**。7 択では UNDECIDED・HEARSAY・POSSIBLE の完全一致が 1.00、DONE 0.96、PLANNED 0.93、WANTED 0.87 で、7 択のほうが状態を取り違えにくい(V2 の「いいえ」系が 0.941 と少し低いのは、回答が記号として解釈できなかった 4 件(WANTED)と、PLANNED・WANTED を POSSIBLE・HEARSAY(未確定側)と答えた 4 件による。無回答を誤りに数えているので、V2 の「いいえ」系は参考値)。
- **few-shot(V3)は逆効果**(UNDECIDED -11.1pt、有意でない。誤答は「いいえ」15 件で V0 の 9 件より多い)。例示が「いいえ」への偏りを強めた可能性があるが、原因は検証していない。

## #20 以降の QA への示唆(要再評価)
- **3 択(V0)で測った結果は、UNDECIDED が多い条件で過小評価されている可能性がある**: #20(メモリ QA)、#59(Long-term Memory、R-M1 の検索ではなく R-M2 の回答)、#62(状態が変わる記憶、R-M4・R-M5)。特に SCF-L1 の記憶は、V0 で UNDECIDED が 0.40 と低く出るため、SCF-L1 の評価が不利になっている(R-M2 の SCF-L1 -8.3pt、R-M5 の迷い遷移の低さの一部)。**V1 の指示で #59・#62 を再測定する必要がある**(RESEARCH_MAP の U15)。
- **7 択(#49、#33 再実行、#54、#57)は影響を受けにくい**(状態そのものを選ばせるため)。#49 の SCF-L1 の想起低下(願望・完了の取り違え)は、この結果では説明されない(#67 の SCF-L1 の弱点は UNDECIDED、#49 は WANTED・DONE)。

## 限界
