# Issue #11: 多言語(EN/KO/JA)→ 共通 MKW

[← README に戻る](../README.md) ・ [用語(NF/SCF/SeCF)](terminology.md)

> 表記: 本書の L0 = NF、L1 = SeCF-L1(構造化 Fact から作る電報体)、L5 / MKW / IR = SeCF-L5(Issue #35)。以下は当時の旧称のまま記述している。

同一の Canonical Facts から EN/KO/JA の L0・L1 と MKW を生成して比較(`i18n.py` `mlenc.py`)。**MKW は関係・演算子・概念語を漢字(言語非依存)に統一し、
固有名詞(人名・愛称・都市・会場)だけ原言語の表記**を保つ。完全版は [results/ml_report.md](../results/ml_report.md)(3言語の実例・全表)、[results/ml_table.csv](../results/ml_table.csv)、`results/ml_pareto_*.svg`。

```bash
scripts/run_ml.sh                      # 本格実行(再開可能, 約3.3時間)
python3 -m machine_kanbun longqa --model google/gemma-4-12b --lengths 2000 --variants EN-L0 KO-MKW EN-MKW@JA --out results/ml
python3 -m machine_kanbun mlconv --model google/gemma-4-12b --length 2000   # 各言語の文 → MKW を LLM で直接変換(日本語を経由しない)
python3 -m machine_kanbun mlreport
```

## 同じ人物の3言語 × MKW(抜粋)
```text
EN-MKW: 人物Ishida{生:1972;職:医療;住:Nagoya;愛称:Yoshi;食{鍋好;酒不飲;疑:レバー不食;好:山>海};…}
KO-MKW: 人物이시다{生:1972;職:医療;住:나고야;愛称:요시;食{鍋好;酒不飲;疑:レバー不食;好:山>海};…}
```

## 所見
1. **MKW のトークン数は言語にほぼ依らない**: 3言語の変動係数は MKW 0.8〜1.1%、L1 8〜13%、L0 12〜18%(o200k・gemma・qwen のどれでも)。L0 は言語で大きく変わる(2k 相当 gemma: EN 1717 / JA 1899 / KO 2296)のに対し MKW は 879〜901。
   ただし**これは設計上の帰結**(概念・演算子を漢字に正規化し固有名詞だけ残す)で、LLM が自力でそう変換した結果ではない。
2. **精度は言語依存で、MKW が L1 に勝つ言語は無い**。MKW − L1(文脈長プール, 対応あり): gemma は JA ±0pt、EN **-5.7pt**(0/11, p<0.01)、KO -1.6pt(p=0.51)。qwen(2k)は KO -16.7pt(p=0.01)、EN -4.2pt。
   日本語以外では「MKW = 日本語要約相当」とは言えない。
3. **英語での低下の主因は「不確実性」**: EN-MKW の不確実性は 45%(L1 は 100%)。`疑:` を凡例なしで英語文脈から読めず、`疑:生卵不食` をそのまま「確定」と答える。不確実性を除くと EN-MKW の誤答は 7/181、EN-L1 は 2/181。#4 の知見(凡例が不確実性に効く)と整合する。**凡例を付けた条件は未測定**。
4. **質問言語の効果は無い**: 日本語固定質問(`@JA`)と同言語質問の差は ±2pt 程度で符号も一定しない。低下は質問言語ではなく**文脈の表現**(漢字 IR + 原言語の固有名詞)に由来する。
   (注意: `@JA` では「石田」↔「Ishida」の固有名詞対応も必要で、純粋な言語固定ではない。)
5. **トークン削減率は言語で違う**(gemma 8k, L0 比): MKW は JA -54% / EN -49% / KO -61%、MKW の L1 比は JA +1.6% / EN +5.6% / **KO -10.7%**。cold TTFT は KO で L0 85 秒 → MKW 35 秒(-59%)。韓国語では MKW のトークン優位が最も大きい。
6. **直接変換(各言語の文 → MKW, 日本語を経由しない)**: gemma 2k で 61〜69 秒・出力約 900 tok。正解 IR との項目 F1 は JA 0.72 / EN 0.52 / KO 0.45 と**言語順に低下**(固有名詞表記の一致を要求する厳しい指標)。変換結果での QA 精度は JA 98% / EN 88% / KO 90%(正解 IR では 100 / 96 / 96%)。
   変換結果を再利用すれば元が取れる回数: 時間で約 5〜7 回、token で約 3〜4 回(出力 5 倍重みで約 5〜8 回)。**8k の EN/KO は出力が上限 8000 tok に達して打ち切られ**(`results/ml_report.md` に明記)、数値は参考値。

## 制約・未達
- **1 seed・各セル 48 問**。差の多くは誤差範囲(95%CI は ±4〜10pt)で、有意なのは上記の gemma EN と qwen KO、全言語プールのみ。
- **採点を 3 回修正した**(英語・韓国語の否定表現、概念語の自由な訳「医療→Medical」、英語の月名・韓国語の同義語)。保存済み回答は全て最新の採点で再計算したが、**直接変換の QA 精度は回答が未保存のため旧採点**で、過小評価の可能性がある。比較問題(`好:A>B`)は答えに両方の語が含まれても正解にする緩い判定。
- 英語・韓国語の文は手書きテンプレート(合成データ)で、語彙・文型は限定的。自然さは未検証。
- qwen は #4 の LM Studio 不具合のため 2k のみ。gemma の 32k は全文(L0)が実行不能(全言語でコンテキスト超過)で圧縮形式のみ。
- **未実施**: EN/KO/JA の L1 → MKW、ルールベース/形態素解析/小型 LLM による変換との比較、言語横断 QA(文脈と質問の言語が異なる全組合せ)、#10 の L1 アブレーションとの統合、凡例あり条件。
